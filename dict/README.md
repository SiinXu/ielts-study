# 离线词典（划词释义用）

- 数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License，© skywind3000），按首字母分片 `a.js … z.js`，划词时才按需加载对应分片。
- 收录：带考试标签（中考/高考/四六级/考研/托福/雅思/GRE）、柯林斯星级、牛津 3000 或词频前 25000 的单词，加本站内容里出现过的所有单词和 1100+ 个短语，共约 3.4 万词条 + 2.9 万个变形（过去式、复数等）指向原形。
- 例句取自本站自己的英文内容（同一词最多 2 句）。
- 每个分片：`IELTS_DICT_SHARD(首字母, {词: {p:音标, g:[中文释义行], d:英文释义, t:标签 I=雅思 T=托福 6/4=六/四级 G=GRE K=考研, c:柯林斯星级, x:[例句]}}, {变形: 原形})`
- 重新生成：`/workspace/dict/build_dict.py`（需要 ecdict.csv）。
